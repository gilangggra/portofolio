# Portofolio Gilang Ramadan

Website portofolio resmi Gilang Ramadan, Full-Stack & Software Engineer. Dibangun menggunakan Next.js App Router, TypeScript, dan Tailwind CSS dengan prinsip desain modern ala macOS yang minimalis, cepat (60fps), dan aksesibel (WCAG AA).

## Tech Stack
- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide Icons & Custom SVG
- **Animations:** Motion & CSS transitions
- **Accessibility:** Standar kontras WCAG AA (minimum 4.5:1), keyboard navigable

## Menjalankan Proyek Secara Lokal

1. **Instal dependensi:**
   ```bash
   pnpm install
   ```

2. **Jalankan server pengembangan (dev):**
   ```bash
   pnpm dev
   ```
   Buka [http://localhost:3000](http://localhost:3000) di browser.

3. **Build untuk produksi:**
   ```bash
   pnpm build
   ```

4. **Jalankan hasil build:**
   ```bash
   pnpm start
   ```
